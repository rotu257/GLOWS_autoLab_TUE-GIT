# GLOWS AutoLab

Python scripts for automated laboratory measurements and instrument control in the GLOWS experimental setup.

This repository contains scripts for controlling laboratory instruments, running measurement jobs, saving waveform data, and supporting repeatable optical/electronic experiments.

## Repository Structure

```text
GLOWS_autoLab_TUE-GIT/
├── instrument_scripts/   # instrument-control scripts
├── job_scripts/          # experiment/job execution scripts
├── configs/              # example configuration files
├── data/                 # local data folder
└── results/              # local output folder
